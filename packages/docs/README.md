# Mimi

A Carbon-based documentation framework with Markdown rendering, multilingual static search and independently deployed product sites.

```sh
npm install @popcornt/mimi @carbon/react react react-dom react-router
```

Import UI from `@popcornt/mimi`, styles from `@popcornt/mimi/styles.css`, and build-time helpers from `@popcornt/mimi/content`. Do not import the content entry into browser code.

See https://github.com/PopcornT/mimi for working React Router examples, configuration, content conventions and deployment guidance. React 19.2+, Carbon React 1.96+ and React Router 7.18.2+ within their declared major versions are required. Uses global Carbon CSS. Markdown is trusted repository content; MDX is not supported.
