# Mimi 0.1.0

First official release under the Mimi name. Routine updates stay on 0.1.x; larger version changes are reserved for a major redesign. The earlier @popcornt/mimi 0.2.0 publication used a pre-branding version number by mistake and is superseded by 0.1.0.

## Pre-release development history

# 0.2.0

- Remove Fumadocs Core and its transitive dependencies.
- Own content lookup, portable static search data, multilingual matching and React loading lifecycle.
- Search JSON format changed: rebuild and deploy pages and indexes together.

# Changes

## 0.1.0 (local release candidate)

- Carbon documentation layout with mobile navigation, theme/language controls and keyboard-accessible search.
- Fumadocs Core source indexing and static multilingual search.
- Markdown, images, Carbon code snippets/tables, math and Mermaid.
- Static HTML, canonical/alternate links, sitemap, robots and LLM text exports.
- Locale fallback, legacy hash URL migration, packaged fonts and independent consumer installation checks.

Not published. MDX and document version snapshots are outside this initial release.
